# 📊 Superstore Sales Performance Overview

## 📌 Project Overview

Superstore Sales Performance Overview is an end-to-end data analytics project built using Python, SQL, and Power BI. The project analyzes sales performance, customer segments, products, regions, and time-based trends to generate actionable business insights through interactive dashboards.

## 🛠️ Tools \& Technologies

* **Python** — Data cleaning and exploratory data analysis
* **Pandas** — Data manipulation and analysis
* **Matplotlib \& Seaborn** — Data visualization
* **SQL** — Business analysis and data querying
* **Power BI** — Interactive dashboards, KPIs, and visual analytics

## 🔄 Project Workflow

1. Data Collection
2. Data Cleaning and Preparation using Python
3. Exploratory Data Analysis (EDA)
4. Business Analysis using SQL
5. Data Visualization and Dashboard Development using Power BI
6. Sales Trend and Forecast Analysis
7. Business Insights Generation

## 💡 Key Insights

* Total sales reached **₹191.29M** across approximately **5K orders**.
* The **West region** generated the highest sales at approximately **₹78.35M**.
* **Technology** was the highest-performing product category, generating approximately **₹70.18M** in sales.
* The **Consumer segment** contributed the largest share of sales at approximately **₹97.37M (50.9%)**.
* Sales increased strongly from **2016 to 2018**, reaching approximately **₹61M in 2018** in the overall sales view.
* The forecasting dashboard indicates stronger sales activity toward the end of the year, with notable peaks in **November and December**.
